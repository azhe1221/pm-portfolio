# 周桂俊｜AI 产品经理作品集（公开发布版）

部署时将本目录作为网站根目录，访问入口为 `index.html`。

公开内容包括：

- 两个项目案例页、可运行 Demo、低保真线框和指标看板。
- 精选 PRD、用户研究、AI 架构、指标、评测、商业假设和产品反思。
- 所有项目均明确标注为个人项目、验证前原型和模拟/合成数据。

未放入公开目录的内容包括：面试讲解手册、面试速查卡、高频追问回答库、简历项目与自我介绍素材、岗位定向关键词与投递清单。这些文件仅用于个人面试准备。

## 本地检查

直接双击根目录 `index.html` 可浏览案例页。两个 Demo 都是静态页面，不依赖本地服务器。

## GitHub Pages

将本目录的全部内容推送到 GitHub 仓库后，在仓库设置中选择 `Settings → Pages → Deploy from a branch → main / (root)`，等待生成公网地址即可。
