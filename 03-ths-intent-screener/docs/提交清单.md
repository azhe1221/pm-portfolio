## 2. 公网 URL（必须替换）

题目要求“可访问、可实际操作的 Web 产品 URL”。当前本地地址是：

```
http://127.0.0.1:8080
```

**提交前需要部署成公网地址**，三选一：

### A. GitHub Pages（最省事，纯静态）

1. 新建公开仓库（不要提交 API Key）。
2. 把 `1/` 目录**里面的内容**推到仓库根目录（`index.html` 在根）。
3. Settings → Pages → Deploy from a branch → `main` / `(root)`。
4. 等 1–2 分钟，得到 `https://<用户名>.github.io/<仓库名>/`。
5. 确认 `data/snapshot.json` 能访问（4.42 MB，GitHub Pages 限制内）。

> 静态模式下 `/api/health` 会 404，页面会自动使用本地解析器；这是设计好的降级，不是故障。

### B. Vercel / Netlify（纯静态）

- 直接拖拽 `1/` 目录，或连接仓库；无构建命令，输出目录为根目录。
- 不需要环境变量。

### C. Node 托管（需要 LLM 时）

- 启动命令：`node server/server.js`
- 环境变量：`PORT`（平台通常自动注入）；可选 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL`。
- 平台需要支持 Node 18+。

部署后把 URL 填到：

- 提交表单/邮件
- README 的“快速开始”
- 面试讲解里的演示链接
